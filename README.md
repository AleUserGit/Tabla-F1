# TABLA WDC, WCC F1

## El programa permite crear dos tablas donde llevar la cuenta de puntos del campeonato.
### En la primera lleva el Campeonato Mundial de Pilotos (WDC), donde permite anotar puesto, piloto, puntos y escudería. La segunda es para el Campeonato Mundial de Constructores (WCC), donde permite anotar puesto, constructor y puntos. Ambas pueden modificarse para agregar los puntos corresponidentes luego de cada evento. Se reordenan automáticamente.
