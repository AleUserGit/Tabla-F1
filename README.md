# TABLA DE PUNTAJES PARA JUEGOS

## El programa crea dos tablas donde llevar la cuenta de puntos de una competencia o juego.
### Requiere tipo de jugador ("Piloto", "Vendedor", "Futbolista") y tipo de equipo ("Escudería", "Tienda", "País"). Luego, el usuario elige cuántos equipos participan, y asigna jugadores a cada equipo. El usuario puede ingresar cuántos puntos obtuvo cada jugador en cada ronda, y el programa calcula automáticamente el orden de la tabla, así como cuántos puntos recibe cada equipo.
### La cantidad de jugadores debe equivaler al doble de equipos, obligatoriamente.
### Funciones pendientes: peristencia de datos, menú de opciones, varias tablas distintas, mayor flexibilidad respecto a los jugadorees y sus equipos.
